# ST-221 Type 2a composition plan (2026-10-10)
1. Private factory only: `createBrowserSubscriptionReadApp(options)` composes `BrowserSubscriptionReadHttpController` and `BrowserSubscriptionReadHttpService`; default AppModule and v1 graph stay untouched.
2. Trusted options name owned fixture database `browser_subscription_read_proof`, ordinary LOGIN role `st221_runtime`, runtime group `subtrack_runtime`, fixture table owner `fixture_owner`; caller supplies the same `PrismaClient` pool used for preflight and scoped read.
3. Actual v2 ports: `accessTokens: Pick<V2AccessToken,'verify'>`, `principal: Pick<DevelopmentV2PrincipalResolver,'resolve'>`, `repository: Required<Pick<SessionRepository,'readSession'|'webContextForCurrentSession'>>`, `csrf: Pick<SessionCsrfGuard,'verify'>`, `clock: () => number`.
4. Adapter performs verified access `sid/sub` → `readSession(sid,{userId:sub},now)` → `webContextForCurrentSession(sid,{userId:sub},observedBindingHash,exactOrigin,now)` → `resolve(access,{transport:'web',exactOrigin,browserChainId})` → `verify({identityId:sub,sessionId:sid},csrf)`; no v1-shaped verifier bridge.
5. Graph injects only `SubscriptionReadService(new SubscriptionReadRepository(options.prisma))` into the accepted adapter, preserving its scoped transaction and owner visibility; no injectable read callback or lifecycle writer.
6. Before Nest create/init/listen, same-pool SQL checks exact database/role, LOGIN, non-superuser, non-BYPASSRLS, one `subtrack_runtime` membership, and fixture-owned RLS plus SELECT on identity/session/household/household_member/consent/subscription/subscription_share.
7. Separate same-pool check requires fixture-owned public `merchant` and SELECT for the detail LEFT JOIN; merchant is a public catalog table and is not required to have RLS.
8. Factory requires explicit development enablement and denies `NODE_ENV=production`; launcher later proves disposable fixture provenance before constructing Prisma. No ambient `DATABASE_URL` or pool creation here.
9. Direct HTTPS only from explicit caller-owned ephemeral TLS key/certificate bytes, no file operations; bind `127.0.0.1` at an explicit positive port matching sole exact allowlisted `https://127.0.0.1:<port>` Origin. No proxy/plain HTTP fallback.
10. Nest uses `rawBody:true` and bounded JSON parser; parser failures (encoding, content type, size, malformed JSON) produce fixed four-field 400 `INVALID_SUBSCRIPTION_QUERY`, `application/problem+json`, `no-store` before controller; other framework/storage failures mask to fixed 500 `INTERNAL_ERROR`.
11. Bound preflight/create/init/listen/close; timeout or rejection starts idempotent cleanup, and late create/init/listen resolution triggers another close so no app-owned listener survives. Never log raw errors, URLs, keys or identities.
12. Returned `close()` is idempotent and releases the app-owned listener; the caller retains responsibility to disconnect its injected Prisma pool and dispose its injected auth/session/CSRF ports and TLS material.
13. Composition tests prove graph and pool identity, preflight denial before Nest, negative TLS/Origin/port/parser cases, bounded late operations/cleanup, and unchanged default graph; actual HTTPS browser plus owned PostgreSQL proof belongs to ST-222.
