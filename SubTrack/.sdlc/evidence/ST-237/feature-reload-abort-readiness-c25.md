# ST-237 independent security/platform readiness — C25 reload abort

**Decision: conditional Type 2a source GO for the narrow proof-transport correction; actual feature HOLD.** At frozen C24 head `fd8c37adbddabec9c9ad932ba56397301d9219c7`, all four Firefox variants saved and separately read the profile, then failed in `page.reload()` with `reloadError=ABORT` and `reloadPageClosed=NO`. Three observed an aborted main-frame document request; one recorded `NONE`. These markers do not establish what initiated the abort or whether any reload document committed. The original L240 deadline remains `2026-10-11T16:53:20.061Z` with its counters unchanged.

The proposed observation is defensible only as an alternate way to prove that the **same single reload** committed despite Playwright rejecting its awaited call. Before calling `page.reload({ waitUntil: 'domcontentloaded' })` once, capture the current page's `performance.timeOrigin` and its exact private register URL, including the existing `st237_probe` query, in private memory. Arm a response listener for a main-frame **navigation document** whose URL equals that captured URL and whose status is exactly 200; count only responses observed after the reload attempt begins. If the reload call returns, preserve the existing success path. If it throws, use the fallback only for the confirmed `ABORT` class while the same page remains open. Within the existing 45-second wait budget, require all three independent observations: the matching 200 document response, a new `performance.timeOrigin`, and a Navigation Timing entry with `type === 'reload'` in the resulting page. A response alone can precede an aborted commit; a new document alone could be an unrelated navigation. Do not infer success from either one.

Keep the current screenshot, localized verified-login stop, mounted editor absence, and partial-terminal cookie assertions mandatory after the observation. No second `reload`, retry, route change, manual navigation, timeout increase, server or product change, cookie/security relaxation, or acceptance on an old page is within this GO. Do not print the URL, query, exception, response body, credentials, or document content; any additional reporter field must remain a fixed closed enum in both anchored harness allowlists. Detach the temporary listener after this phase. If the 200 response, changed time origin, or reload timing entry is missing, fail the proof and retain HOLD.

This readiness decision does not claim that HMR, Next, or any particular component caused the abort. The author must present a small exact diff for independent source review before push. A fresh exact-head four-variant natural-browser run through all later gates, independent actual QA, applicable CI, and Conductor audit remain necessary for feature acceptance.
