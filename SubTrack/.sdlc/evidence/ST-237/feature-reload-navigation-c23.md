# ST-237 C23 reload navigation diagnostic handoff

The C23 exact-head matrix at `9f0894c` reached the saved and separately read profile in all four Firefox variants, then failed with `phase=RELOAD_NAVIGATE`, `reloadStatus=NONE`, and `reloadNavigation=NONE`. The driver assigns `reloadStatus` immediately after `await page.reload({ waitUntil: 'domcontentloaded' })`; therefore the observed failure happened before that call returned. No `reloaded.png` was produced. This narrows the C22 combined reload failure to browser navigation, but does not identify its underlying cause. The fresh Next/HTTPS process restart and committed lost-response PATCH preceded this call; neither is proven causal.

This bounded diagnostic adds a closed classification of the caught reload error (`NONE`, `TIMEOUT`, `TLS`, `CONNECTION`, `ABORT`, or `OTHER`), whether the primary page is closed (`NONE`, `YES`, or `NO`), and the same closed classification for a failed main-frame document navigation request. The classifier compares transient Playwright error name/message or `request.failure()?.errorText` against fixed patterns and emits only the fixed labels. If Playwright cannot resolve a navigation request's frame, the listener records `OTHER` without throwing. It does not emit an exception, URL, query, body, cookie, credential, profile value, console message, or trace. It leaves `page.reload`, navigation wait, localized stop text, editor-absence check, later partial-terminal proof, and all timeouts unchanged.

The Conductor must extend both exact-line reporter allowlists with `reloadError=(NONE|TIMEOUT|TLS|CONNECTION|ABORT|OTHER) reloadPageClosed=(NONE|YES|NO) reloadRequestFailure=(NONE|TIMEOUT|TLS|CONNECTION|ABORT|OTHER)` after `reloadStatus`. Interpret a `TIMEOUT` as a Playwright navigation wait failure, `TLS` or `CONNECTION` as transport classes, `ABORT` as a canceled navigation, and `OTHER` as an unclassified failure. `reloadRequestFailure=NONE` only means no failed main-frame document request was observed; it does not prove document loading succeeded. The runtime cause and feature acceptance remain HOLD until a fresh exact-head actual matrix and independent review.
