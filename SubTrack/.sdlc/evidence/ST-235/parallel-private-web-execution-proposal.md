2. Create a new M≤120-minute dev-web task, parallel to ST-235/next durable enrollment, for an unmounted, reusable profile editor; exact source GO/freeze after client-design, security and QA readiness. 3. Until integration, render only in component tests; show no saved/signed-in/success claim in product routes.

A separate `JustMeChoice` control accepts only a persisted completed view and emits `parseJustMeChoice({mode:'just-me'})`; server must repeat the completed-profile gate later.
