# ST125f plan review

**Decision: APPROVE_PLAN — Type 2b (local module behavior).** The proposal is a pure offline review export within the existing clustering module. It adds no dependency, API, job, model registry, schema, database, authentication, provider, money computation, or runtime default. This approval covers the local artifact contract and one explicitly authorized root evaluation fit; it does not represent production integration or completion of F9.4.

## Recommended stable API

Add `services/ml/app/clustering/review_artifact.py` with `build_persona_review_artifact(clusterer: PersonaClusterer) -> PersonaReviewArtifact` and `persona_review_artifact_json(artifact: PersonaReviewArtifact) -> str`. Keep exports private to the ML package unless the existing package convention requires a module export. Define frozen, slotted dataclasses for the artifact and nested records. Store only immutable primitives and tuples: fixed `artifact_schema_version` (`persona-review-artifact-v1`), canonical `feature_schema`, the exact constant feature-name tuple, selected `k`, actual training sample count, fixed fit settings (`random_state`, `n_init`), a tuple of canonical centroid descriptions, a tuple of actual fitted label counts ordered by cluster ID, silhouette sample size, ordered scored candidates, and ordered skipped `k` values. Avoid redundant free text, source/hash claims, individual labels/assignments, input rows, IDs, model/scaler references, or caller-supplied metadata.

The builder accepts only an actual fitted `PersonaClusterer` with canonical schema/name metadata and internally calls the existing `describe_persona_centroids`. Validate consistent fitted KMeans and scaler state before producing output: selected `k` in 4..8; 9..5,000 training rows; 25 features; labels are a one-dimensional integer array of exactly the training length with values in `0..k-1`; every selected cluster has a positive count; estimator/scaler fitted sample and feature metadata agree where sklearn exposes them; finite, in-range scores; distinct ascending scored candidate `k`s in 4..8; distinct ascending skipped candidates; scored and skipped candidates are disjoint and together account for all 4..8; selected `k` is the greatest actual score with an exact tie resolved to smaller `k`; actual model settings agree with the clusterer's recorded settings and have meaningful bounds. Require silhouette sample count 9..min(training rows, configured sample cap), consistent with `silhouette_sample_size_`. Use conservative documented bounds for integer settings and reject booleans as integers. Any malformed or inconsistent state raises a stable `ValueError` that does not include values, row contents, labels, or arbitrary text. Catch only expected conversion/attribute errors and translate them to that same safe error family.

The artifact constructor must not accept a model, labels, centroids, or arbitrary text from a caller. Freeze all nested data by building tuples and primitive copies. Serialization accepts only the artifact type, emits a fixed key layout with `json.dumps(..., allow_nan=False, sort_keys=True, separators=(",", ":"))`, and raises `ValueError` for non-finite or unsupported state. Repeated serialization of the same artifact must be byte-identical and parse as strict finite JSON. No I/O, fitting, prediction, logging, network calls, pickle, loader, or registry behavior belongs here.

## Evidence and scope boundaries

`AI_ML_SPEC.md` §3 describes 5,000 synthetic households for clustering but does not make a saved model or private review artifact a production model. Existing ST125c evidence records a 5,000-by-25 lightweight statistical synthetic input, SHA-256 `7d3fcff47e610e56f705359b38f6c107e9eaca45be6dd2ac7c0557105dca0d8b`, seed 42, `n_init=10`, one numerical thread, 1,000 silhouette rows, selected `k=8`, scores for all `k=4..8`, no skipped candidates, and counts `(582, 841, 827, 996, 227, 945, 342, 240)`. It reports weak separation (selected silhouette `0.13414094511155428`) and expressly disclaims representativeness, target quality, ground truth, frozen labels, cohorts, and integration.

The old evaluation contains no saved estimator or centroids, and its generic fit did not carry the canonical schema marker. Root may reuse its input only after verifying the exact file bytes against that recorded SHA-256, exact canonical 25 feature names/order, shape `(5000, 25)`, finite values, and schema bounds. Root may perform **one** new, local, single-threaded fit on that verified input with the recorded seed/config and explicit canonical schema marker to create the required actual centroid review artifact. The new artifact must be attributed only to that new fit. Record the input digest and exact fit invocation in external review evidence beside the artifact; neither input digest nor synthetic origin is proven by fields inside this primitive. If hash or feature validation fails, stop and report the mismatch rather than reusing or relabeling the old evaluation. This one fit is justified by the requested new centroid artifact and remains inside the accepted private offline synthetic evaluation scope.

The data source is authorized synthetic test material; a trusted local caller remains responsible for establishing its origin and scope. A canonical schema marker establishes the caller's declaration and shape contract, not semantic column proof, authenticity, authorization, or real-household validity. The output is statistical evidence only. Do not infer household personas, money values, spend claims, semantic labels, cohort quality, or useful separation from these centroids. Human-reviewed naming and integration stay separate. Do not add Type 1 changes or alter the parent ST125 partial status.

## Meaningful QA contract for the implementer/root

Focused fixtures should use small valid fitted canonical models and verify counts independently from `model.labels_`, centroid reuse, exact candidate/skipped accounting and tie handling, deterministic JSON parsing/string equality, deep immutability, and no label/row/model leakage in serialized keys. Malformed labels (wrong shape/length, float/bool/out-of-range, missing cluster), scores (NaN/infinity/out-of-range/duplicate/order/incorrect winner), fit metadata, scaler/model shape, and sample bounds should fail safely. Assert construction does not invoke `fit` or `predict`; do not add a routine 5,000-row unit fit. Root may run its planned focused tests and existing regression/security/CI gates separately. Keep changes within the proposal's allowed paths and add a concise model-card note that clearly reports weak synthetic separation and limits.
