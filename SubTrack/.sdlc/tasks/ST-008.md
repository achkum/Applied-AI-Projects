## Goal
Create the web application shell with routing, Swedish/English locale selection, system/light/dark theme selection, and the generated API client available to application code.
## Context (read before starting)
- BACKLOG_SEED.md ST-008
- ROADMAP.md §M0
- ARCHITECTURE.md §§2–3
- ADR-0004

## Acceptance criteria
- AC1: Given a fresh install using the workspace scripts, when the web app is built, then the Next.js App Router production build succeeds and the root route renders.
- AC2: Given locale `sv` or `en` is selected, when a representative shell label renders, then it comes from that locale catalog; both catalogs expose identical keys and unsupported locale selection falls back to the documented default.
- AC3: Given theme preference is `system`, `light`, or `dark`, when the shell renders or the OS preference changes, then the selected mode is applied; explicit light/dark override system preference.
- AC4: Given ST-006 generated artifacts exist, when app code imports the API client, then it imports the generated package entry point rather than defining duplicate API types.
