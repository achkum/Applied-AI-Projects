## HANDOFF/v1
- **Implemented by**: claude-code (direct)
- **Stack**: Storybook 8.6.18 + `@storybook/react-vite` + `@storybook/addon-essentials`; visual regression via `@storybook/test-runner` 0.19 + `jest-image-snapshot`
- **Storybook build command**: `pnpm --filter @subtrack/ui storybook:build` → outputs to `packages/ui/storybook-static/`
- **Storybook dev command**: `pnpm --filter @subtrack/ui storybook` → runs at port 6006
- **Visual regression command**: `pnpm --filter @subtrack/ui storybook:test` (requires Storybook running at port 6006; first run writes PNG baselines; subsequent runs compare and fail on pixel diff > 0.01%)
- **AC1 — Storybook starts + discovers stories**:
  ```
  storybook build --quiet
  ✓ built in 3.71s
  Output directory: packages/ui/storybook-static
  Bundle includes: Button.stories-DkCUvE7Y.js
  ```
  Dev server: HTTP 200 at localhost:6006
- **AC2 — Named story states discoverable**:
  `Button.stories.tsx` exports 4 named stories with deterministic fixtures:
  - `Primary` (variant=primary, children="Continue")
  - `Secondary` (variant=secondary, children="Cancel")
  - `Disabled` (variant=primary, disabled=true)
  - `DisabledSecondary` (variant=secondary, disabled=true)
  Global theme toggle (light/dark) via `data-theme` attribute on wrapper div; `@subtrack/ui-tokens/tokens.css` provides CSS custom properties for both themes.
- **AC3 — Visual regression**:
  ```
  test-storybook --url http://localhost:6006 --stories-json
  Tests: 4 passed, 4 total
  Snapshots: 4 written (first run) / 4 passed (subsequent runs)
  ```
  PNG baselines committed at `.storybook/__snapshots__/*.png`; `postVisit` hook in `.storybook/test-runner.ts` calls `toMatchImageSnapshot` with `failureThreshold: 0.01%`.
- **Placeholder component**: `Button` (primary/secondary/disabled) in `packages/ui/src/components/Button/` — demonstrates Storybook theming end-to-end; replaced by actual product components as ST-024 lands.
