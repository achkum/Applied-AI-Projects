## Goal
Create the pnpm/Turborepo monorepo foundation and shared config package in accordance with accepted ADR-0001 and the M0 roadmap.

## Acceptance criteria
- AC1: Given a clean checkout, when `pnpm install --frozen-lockfile` runs at `SubTrack/`, then workspace packages under apps/, packages/, and services/ resolve without lockfile changes.
- AC2: Given the root Turbo configuration, when `pnpm check` runs, then Turbo schedules lint, typecheck, and test tasks with workspace dependencies built first; each task has a package-level script or an explicit documented no-op only where no code exists.
- AC3: Given the shared TypeScript config, when a workspace package compiles, then strict mode is enabled by inherited config and a fixture/import check confirms disallowed cross-layer imports are rejected by ESLint boundaries.
- AC4: Given the shared `@subtrack/config` package, when a consumer imports its declared public entry point, then typecheck/build resolves through the workspace protocol; `pnpm format:check` reports no formatting changes.
- AC5: Given the monorepo scope, when these checks run from the SubTrack root, then all succeed without writing files outside the allowed paths.
