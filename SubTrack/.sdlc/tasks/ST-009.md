## Goal
Create an Expo Router application shell with locale and theme foundations, secure-storage abstraction, and development/preview/production EAS profiles.

## Acceptance criteria
- AC1: Given a fresh workspace install, when the mobile app starts in its supported local development target, then Expo Router loads the root route without a runtime error.
- AC2: Given locale `sv` or `en` is selected, when a representative shell label renders, then it uses the matching catalog and key parity is verified; no user-facing hard-coded string is introduced.
- AC3: Given system/light/dark theme preference is selected, when the app renders, then the chosen theme is applied and explicit light/dark overrides system preference.
- AC4: Given a value is written/read/deleted through the secure-storage adapter, when the adapter API is exercised, then it delegates to platform secure storage and never falls back to plaintext storage.
- AC5: Given EAS profiles are evaluated, when development, preview, and production profiles are selected, then each is named and has distinct build configuration; no production credential/identifier is fabricated.
