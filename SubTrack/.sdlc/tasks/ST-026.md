## Goal
Implement three mobile signature components (RollingNumber, ScopeSwitcher, ReceiptCard) using React Native with Reanimated motion, locale-aware formatting, category-aware colors, and full accessible/reduced-motion support per Norrsken design.

## Context (read before starting)
- docs/product/DESIGN_DIRECTION.md §4 (components 3, 4, 2), §3 (motion: Reanimated spring damping 18, stiffness 180), §6 (layout)
- docs/governance/QUALITY_GATES.md (test pyramid, accessibility RN accessibility props)
- ST-023 component specifications (once DONE)
- `packages/ui-tokens`: category-hue tokens (RN theme), reduced-motion value

## Acceptance criteria
- AC1: **RollingNumber**: Hero total (hero frame, Fraunces 64px equivalent, tab-figure numerals), locale-formatted (sv: "1 390 kr", en: "SEK 1,390"), Reanimated digit-roll transition on value change; reduced-motion mode disables animation; jest render test. Storybook (Expo Web) and Maestro test are deferred to ST-039 — not achievable by an agent (no device/simulator/Storybook-native setup exists) and not blocking.
- AC2: **ScopeSwitcher**: Segmented pill (radius 28px), member avatars, tints global accent per scope (Me=violet, Household=green, member=**member-specific accent via `memberAccentForId`**, per ST-030 — not a category hue), accessible RN labels (accessibilityRole="radio", accessibilityLabel, accessibilityState: {selected}), keyboard nav (tab between members)
- AC3: **ReceiptCard**: Editorial layout, price in Fraunces, price-history sparkline (using react-native-svg), category token color, WCAG AA contrast in both themes; jest render/snapshot test. Maestro screenshot test deferred to ST-039.
- AC4: **Haptics**: Light haptic on scope change (requires ST-021 font sync to be DONE for reliable rendering); not dependent on font bundling for MVP behavior (see ST-021 follow-up)
- AC5: **Reduced-motion**: prefers-reduced-motion:reduce disables all Reanimated transitions (instant state), no animations; tested via the `useReducedMotion` hook's jest unit tests (mocking `AccessibilityInfo`). Maestro/device-settings verification deferred to ST-039.
- AC6: **i18n**: All labels/descriptions use i18n context; sv and en keys exist; parity check passes
- AC7: **Test coverage**: Jest unit tests for calculations (this app has no Vitest — jest/jest-expo is the actual toolchain); component render tests via `@testing-library/react-native` once ST-038 fixes the RN/RNTL render-harness incompatibility. Maestro E2E and VoiceOver/TalkBack validation deferred to ST-039 (no device/simulator/Maestro binary available to an agent).
- AC8: Components live colocated in `apps/mobile/src/components/signature/` with tests before app integration (per ADR-0009: `packages/ui-native` is not created — one consumer, no spec mandate); app tests use mock fixture data (real API awaits ST-082)

- Haptic feedback light intensity; document iOS/Android parity in PR
- RN accessibility: use accessibilityLabel, accessibilityRole, accessibilityState for semantic exposure
- Do not edit CI workflows; visual regression test wiring is ST-017 scope
- Any runtime dependency added to `apps/mobile/package.json` (e.g. `react-native-svg`, `expo-haptics`) must also update `pnpm-lock.yaml` (now in `allowed_paths`) — CI runs `pnpm install --frozen-lockfile` and will fail otherwise.
