## Goal
Implement three mobile signature components (RollingNumber, ScopeSwitcher, ReceiptCard) using React Native with Reanimated motion, locale-aware formatting, category-aware colors, and full accessible/reduced-motion support per Norrsken design.

## Context (read before starting)
- docs/product/DESIGN_DIRECTION.md §4 (components 3, 4, 2), §3 (motion: Reanimated spring damping 18, stiffness 180), §6 (layout)
- docs/governance/QUALITY_GATES.md (test pyramid, accessibility RN accessibility props)
- ST-023 component specifications (once DONE)
- `packages/ui-tokens`: category-hue tokens (RN theme), reduced-motion value

## Acceptance criteria
- AC1: **RollingNumber**: Hero total (hero frame, Fraunces 64px equivalent, tab-figure numerals), locale-formatted (sv: "1 390 kr", en: "SEK 1,390"), Reanimated digit-roll transition on value change; reduced-motion mode disables animation; Storybook story (Expo Web) + Maestro test
- AC2: **ScopeSwitcher**: Segmented pill (radius 28px), member avatars, tints global accent per scope (Me=violet, Household=green, member=category), accessible RN labels (accessibilityRole="radio", accessibilityLabel, accessibilityState: {selected}), keyboard nav (tab between members)
- AC3: **ReceiptCard**: Editorial layout, price in Fraunces, price-history sparkline (using react-native-svg), category token color, WCAG AA contrast in both themes; Maestro screenshot test
- AC4: **Haptics**: Light haptic on scope change (requires ST-021 font sync to be DONE for reliable rendering); not dependent on font bundling for MVP behavior (see ST-021 follow-up)
- AC5: **Reduced-motion**: prefers-reduced-motion:reduce disables all Reanimated transitions (instant state), no animations; testable via Maestro device settings or iOS accessibility simulator settings
- AC6: **i18n**: All labels/descriptions use @react-intl or i18n context; sv and en keys exist; parity check passes
- AC7: **Test coverage**: Vitest unit tests for calculations; Maestro E2E for gesture/nav/haptic feedback (iOS simulator + Android emulator); VoiceOver/TalkBack validation (screen reader nav, label pronunciation)
- AC8: Components live in `packages/ui-native` with tests before app integration; app tests use mock fixture data (real API awaits ST-082)
