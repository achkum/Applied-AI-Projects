## Goal
Define 5 deterministic showcase household personas with ground-truth subscription labels, enabling evaluation of the recurring-detection algorithm (ST-080) and powering app showcases and integration tests.

## Context
- ST-062 provides the deterministic RNG and descriptor generation utilities
- ST-065 (SyntheticBankProvider) will use these personas to emit realistic transaction streams
- PRODUCT_SPEC §F5: recurring detection must be evaluable against synthetic ground-truth
- Personas are static TypeScript constants (pre-computed); tests snapshot them to lock the data

## Acceptance criteria
- AC1: 5 distinct `PersonaHousehold` fixtures exported from `@subtrack/synthetic`.
- AC2: Households cover the four `ownerType` patterns: ME, HOUSEHOLD, and MEMBER (with memberIds).
- AC3: Each `PersonaSubscription` has at least 3 `descriptorVariants` (realistic bank-statement strings) and a `groundTruth.isRecurring = true` label.
- AC4: Snapshot tests in `test/personas.spec.ts` lock all fixture data (deterministic, no RNG drift).
- AC5: `pnpm --filter @subtrack/synthetic test` passes with zero failures.

## Out of scope
- Transaction stream generation (ST-065).
- ML/detection algorithm evaluation — ground-truth labels are provided here; evaluation is in ST-080.
- Database seeding — personas are TypeScript constants, not SQL seeds.

## Technical notes
- Descriptor variants use realistic Swedish bank-statement patterns from ST-062 `generateDescriptors` (pre-computed for snapshot stability).
- Amount fields are in SEK öre (minor units); currency hardcoded 'SEK' for showcase simplicity.
- `memberId` references are short lowercase IDs (no UUIDs); kept simple for fixture clarity.
