## Goal
Implement the independently usable offline statistical core of ST-125/F9.4, not the complete persona/cohort product. No network, DB, route registration, deployed model or money computation.

## Must read
SubTrack/AGENTS.md; docs/governance/CONSTITUTION.md; docs/product/AI_ML_SPEC.md §0/3/7; docs/product/PRODUCT_SPEC.md F9.4; existing ML pyproject and tests. Existing synthetic data and catalog are accepted; no clustering source exists on current main.

## Acceptance
- Receive only a finite, rectangular numeric feature matrix supplied by an upstream scoped deterministic feature builder. Reject malformed/degenerate inputs clearly. No identifiers, raw descriptors, accounts or money computation/extraction in this slice.
- Deterministic scikit-learn KMeans with fixed seed and explicit n_init; choose feasible k in4..8 by silhouette with deterministic bounded sampling for large inputs. Record evaluated k/scores/sample size and selection tie-break. Never evaluate invalid one-label/all-singleton collapsed results.
- Stable predictions using the same fitted preprocessing/model; meaningful tests for deterministic results, separated synthetic feature groups, malformed/degenerate matrices, candidate feasibility, and prediction validation. Existing classifier API remains unchanged.
- Honest model card describes algorithm/input boundaries, measured local tests, synthetic-feature evaluation limitations. Parent requirements remain: accepted category-spend-share/count/average-price/cadence feature building in deterministic TS;5000actualsynthetichousehold population; reviewed/frozen bilingual labels; privacy-safe synthetic cohort stats; descriptor clustering; training/artifacts/registry/integration.
- No claims of full ST125 completion or product-ready metrics. Default tests lightweight; root runs existing full ML suite once and a separately recorded5000-row synthetic numeric-feature smoke if useful (not a household training dataset). No dependency or lockfile changes.
- Independent architect-data review and exact-head required CI before Conductor merge. Target<=450changedlines, hardlimit600.

## Out of scope
Financial arithmetic, real household inputs, LLM calls/naming, public endpoints/contracts, DB/migrations/RLS, model registry changes, package/synthetic changes, external providers, deployment.

## Handoff
Implemented the offline core in `services/ml/app/clustering/core.py`, exported as
`PersonaClusterer`. It validates feature matrices, scales with a fitted
`StandardScaler`, evaluates feasible K-Means candidates at k=4..8 using
deterministic silhouette sampling (capped at 1,000 rows), and retains the
selected preprocessing/model pair for prediction. Added focused tests in
`services/ml/tests/test_clustering.py` and a partial model card in
`services/ml/model_cards/persona-clustering-core.md`.

Tests were authored but intentionally not run here; the parent agent owns the
single test execution. No training, 5,000-row smoke, heavy suite, dependency
change, or external service call was performed. Product feature construction,
5,000-household evaluation, labels, cohort statistics, descriptor clustering,
artifacts/registry, and integration remain pending. The tests use small
synthetic numeric matrices and are not product metric evidence.
