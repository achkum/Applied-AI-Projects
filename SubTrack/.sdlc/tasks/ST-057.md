## Goal
Produce high-fidelity coded Storybook stories for the three hero screens (Welcome, Home, Subscription detail) in light and dark themes, sv and en locales, using mocked data. These stories are the G-DESIGN gate evidence reviewed by the founder before mass implementation.

## Context
- docs/product/DESIGN_DIRECTION.md §§2–6 (concept, foundations, signature components, brand moments, layout)
- docs/design/components/ (seven component specs from ST-023)
- packages/ui-tokens (color, type, motion tokens)
- QUALITY_GATES.md G-DESIGN: founder reviews 3 hero screens before mass implementation

## Acceptance criteria
- AC1: **Welcome screen story** — aurora gradient slowly forming the SubTrack wordmark; subtitle in sv ("Allt ni prenumererar på. På ett ställe.") and en ("Everything you subscribe to. In one place."); story renders in both light and dark; reduced-motion variant freezes the gradient.
- AC2: **Home screen story** — Orbit visual (using ST-025 component) showing 3–5 mocked subscription bodies sized by monthly cost, colored by category token; Scope switcher (ST-024) visible; Rolling total (ST-024) showing mocked monthly total in Fraunces 64px; story renders in light/dark and sv/en; accessible list fallback visible.
- AC3: **Subscription detail screen story** — ReceiptCard (ST-024) with mocked subscription data; price in Fraunces; category color from tokens; light/dark; sv/en.
- AC4: All three stories use only `packages/ui-tokens` token names — no hard-coded hex values; locale strings via `packages/i18n`; no invented sample amounts beyond the mocked data shape.
- AC5: Stories are submitted for founder review as G-DESIGN evidence; no merge without at least one `conductor` or `founder` approval.

## Out of scope
- Actual Next.js page implementation (ST-058).
- Backend API integration — all data is mocked.
- Maestro/E2E (ST-039).

## Technical notes
- Storybook stories go in `packages/ui/src/stories/screens/` following the same pattern established by ST-022.
- Each story exports `Default`, `Dark`, `Light`, `ReducedMotion` variants.
- Mocked data shapes must match the types established by contracts in `packages/contracts`.
