## Goal
Provide the deterministic foundation that ST-063 (personas) and ST-065 (BankDataProvider) build on: a seeded PRNG, Swedish calendar utilities, and transaction descriptor variant generation. All output is reproducible given the same seed.

## Context
- ST-063 uses this to generate 5 showcase households with ground-truth labels and snapshot tests
- ST-065 (SyntheticBankProvider) uses this to produce realistic transaction streams
- PRODUCT_SPEC §F5: recurring detection must be evaluable against synthetic ground-truth
- Swedish calendar correctness is critical: settlement timing, charge dates, trial-period end

## Acceptance criteria
- AC1: `createRng(seed)` produces identical output for the same seed; different seeds diverge.
- AC2: `Rng.nextInt`, `pick`, `shuffle`, `nextGaussian`, `fork` all work deterministically.
- AC3: `easterSunday(year)` matches known Easter dates for 2020–2026.
- AC4: `isSwedishBankHoliday` correctly identifies New Year's, Epiphany, Easter weekend, May Day, Ascension, National Day, Midsummer, All Saints', Christmas block, and New Year's Eve.
- AC5: `generateDescriptors` returns distinct `raw` values all containing the merchant name; `normaliseDescriptor` strips common suffixes and title-cases the result.
- AC6: Vitest suite passes; no external dependencies.

## Out of scope
- Persona generation (ST-063) — this task provides the tools, not the data.
- Bank ingestion or API layer.

## Technical notes
- SFC32 PRNG (128-bit state, FNV-1a string seeding + 15-round warm-up).
- Easter algorithm: Anonymous Gregorian.
- Swedish bank holidays include statutory public holidays plus Dec 24, Dec 31, and Midsummer Eve.
- Zero runtime dependencies; devDependency on vitest only.

## Verification evidence
- `vitest run` in `packages/synthetic` — all tests pass.

## Progress
- 2026-10-01 UTC: Implemented. `src/rng.ts` (SFC32 PRNG, fork support) + `src/calendar.ts` (Easter, Swedish holidays, business days) + `src/descriptor.ts` (generateDescriptors, normaliseDescriptor) + 3 test files (40+ cases). Package.json updated with real scripts and vitest devDep.

## HANDOFF/v1
- **Exported API**: `createRng`, `Rng` (interface), `easterSunday`, `addDays`, `isSwedishBankHoliday`, `isSwedishBusinessDay`, `nextSwedishBusinessDay`, `datesBetween`, `businessDaysBetween`, `generateDescriptors`, `normaliseDescriptor`, `TransactionDescriptor`
- **RNG design**: SFC32 with FNV-1a seeding; `fork(label)` creates independent child RNG from parent + label — use this to partition random draws by concern (e.g. `rng.fork('charges')`)
- **Calendar caching**: holiday sets memoized by year in a module-level Map — cheap to call repeatedly
- **ST-063 integration**: call `createRng('persona:<householdId>')` then fork per member/service for independent streams
