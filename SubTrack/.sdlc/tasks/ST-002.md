## Goal
Give the new monorepo a clean root while preserving the useful prototype logic for reference.

## Context
- The current root holds a ~440-line prototype: `src/`, `test/`, `app.js`, `server.mjs`, `index.html`, `styles.css`, `db/`.
- It also holds a nested duplicate `SubTrack/SubTrack/` (with a `.tar.gz`), several `*payload*.json` files, and old plan/spec markdown files.

## Acceptance criteria
- AC1: `git mv` all prototype code and old docs into `SubTrack/_legacy/`, preserving history.
- AC2: Delete `SubTrack/SubTrack/` (including the tarball), `plan_payload.json`, `confirmation_payload.json`, `subtrack-plan-rev2-confirmation.json`.
- AC3: `_legacy/README.md` lists what is worth salvaging: the hash-chained audit design, consent versioning, and the MockBankProvider shape.
- AC4: The old CI workflow is disabled (it targets `npm --prefix SubTrack`); the new one arrives in ST-005.
- AC5: No new files outside `SubTrack/`.
