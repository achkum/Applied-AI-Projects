## Goal
Implement three web signature components (RollingNumber, ScopeSwitcher, ReceiptCard) with locale-aware rendering, category-aware coloring, and full accessible/reduced-motion support per Norrsken design direction.

## Context (read before starting)
- docs/product/DESIGN_DIRECTION.md §4 (components 3, 4, 2 respectively)
- docs/governance/QUALITY_GATES.md (test pyramid, accessibility, visual regression)
- ST-023 component specifications (once DONE)
- `packages/ui-tokens`: category-hue tokens, reduced-motion vars

## Acceptance criteria
- AC1: **RollingNumber**: Hero total displays with Fraunces optical size 64px (dark: #F2EFE8, light: #15161C), tab-figure numerals, locale-formatted (sv: "1 390 kr", en: "SEK 1,390"), and digits roll when values change; reduced-motion mode freezes transition; Storybook story + Playwright visual regression test
- AC2: **ScopeSwitcher**: Segmented pill (radius 28px) with member avatars, tints global accent per scope (Me=violet, Household=green, member=category color), accessible keyboard nav/screen readers (role="group" + aria-label), icon/text labels; Storybook story + interaction test
- AC3: **ReceiptCard**: Editorial layout with perforated bottom edge, price in Fraunces (variable optical size), price-history ticker-tape line, category token color per subscription type; WCAG AA contrast verified; Storybook + visual snapshot test
- AC4: All three components use `@next-intl` for sv/en parity; i18n key parity check passes in CI
- AC5: Accessibility: focus visible, reduced-motion respected (motion freezes, no transitions), VoiceOver labels work; axe-playwright audit passes with no violations
- AC6: Components live in `packages/ui` first with tests/Storybook before integration into app; web app integration tests verify data flow from dashboard API stubs
- AC7: No TODOs without task IDs; existing ADRs cite (architecture decision records for Fraunces/motion choices)

## Out of scope

## Technical notes
- RollingNumber motion uses Framer Motion with spring(damping: 18, stiffness: 180); reduced-motion uses instant transition
- ScopeSwitcher scope change tints full page accent via theme context; reversible without state loss
- ReceiptCard price-history line is SVG sparkline; no external charting library
- Do not edit CI workflows; contrast checker and visual regression are wired by ST-017
