## Goal
Deliver sessions, refresh rotation and device revocation in scope of SubTrack PRODUCT_SPEC, with privacy and security invariants enforced.
## Context
- PRODUCT_SPEC §F1.3, F1.6; DATA_MODEL.md §Identity; ADR-0003
## Acceptance criteria
- AC1: Given successful OTP or BankID auth, when a session is issued, then client receives EdDSA JWT and opaque refresh credential while only refresh-token hash is stored.
- AC2: Given refresh, when rotated, then old token becomes unusable; reuse revokes the token family and requires reauthentication.
- AC3: Given device list/revoke, when user revokes one device, then that device cannot refresh and other devices remain active.
- AC4: Given any user, when requesting sessions, then only own devices are returned.
