## Goal
Generate deterministic demo-tenant JSON snapshots from persona fixtures (ST-063) with a rolling `--as-of` date. Supports nightly automated reseed via a Docker Compose cron service for staging environments.

## Context (read before starting)
- BACKLOG_SEED.md ST-162
- ROADMAP.md §M5

## Acceptance criteria
- AC1: `generateDemoSnapshot(date)` returns a `DemoSnapshot` with 5 households (one per ALL_PERSONAS).
- AC2: All generated transactions fall within the 13-month window ending at asOf.
- AC3: Snapshot is deterministic — same asOf always yields identical output.
- AC4: Docker Compose override `docker/demo-seed.yml` defines a `demo-seed` service with `com.subtrack.cron=0 3 * * *` label.
- AC5: ≥20 tests pass; typecheck clean.

## Out of scope
- Database insertion (blocked on ST-040, ST-060 schema)
- Non-subscription/noise transactions
- Mobile or API integration

## Technical notes
- `noUncheckedIndexedAccess` + `exactOptionalPropertyTypes` in tsconfig: use spread for optional fields
- `services/*` already in pnpm-workspace.yaml
- `toIsoDate()` uses local Date methods (not `toISOString().slice`) to avoid UTC offset drift
