## Goal
Bundle the specified licensed typefaces for the web app with their notices, without runtime font-CDN dependencies. Mobile font bundling is outside this seeded task scope.
## Context (read before starting)
- BACKLOG_SEED.md ST-021
- ROADMAP.md §D1
- DESIGN_DIRECTION.md §3

## Acceptance criteria
- AC1: Given web production assets are built, when font requests are inspected, then Fraunces, Manrope, and JetBrains Mono are served from repository-bundled assets and no third-party font host is required; mobile font bundling is not part of this task.
- AC2: Given the bundled font files are reviewed, when their family/variable axes are inspected, then Fraunces supports the specified display/numeral use, Manrope UI use, and JetBrains Mono code use as available in the selected official font distributions.
- AC3: Given the bundled font distributions are committed, when license files are inspected, then the applicable OFL notices and copyright statements accompany the assets.

## HANDOFF/v1
- **Implementation**: `apps/web/lib/fonts.ts` exports `fraunces`, `manrope`, `jetbrainsMono` (next/font/google instances) and `fontClassNames` string
- **Layout wire-up**: `app/layout.tsx` imports `fontClassNames` and applies it to `<html className={fontClassNames}>` — this sets `--font-display`, `--font-ui`, `--font-mono` CSS variables which the ui-tokens stylesheet already references
- **Font variable axes**: Fraunces loaded with `axes: ['SOFT', 'WONK']` for full variable axis support; Manrope loaded with variable weight range (default); JetBrains Mono `preload: false` (only needed for code blocks, not critical path)
- **Self-hosting mechanism**: next/font/google downloads font subsets at build time and embeds them as optimized woff2 in the build output — no third-party requests at runtime (AC1)
- **OFL notices**: `public/fonts/licenses/OFL-Fraunces.txt`, `OFL-Manrope.txt`, `OFL-JetBrainsMono.txt` — copyright notices from official upstream repos (AC3)
- **Mobile fonts**: out of scope; tracked as open question in ST-016
