## Handoff — v1

### What was built
- `apps/web/app/fonts.ts` — loads Fraunces (opsz/SOFT/WONK axes), Manrope, and JetBrains Mono from `next/font/google`. Fonts are downloaded at build time and served from the Next.js host; no browser requests reach Google's CDN at runtime.
- `apps/web/app/globals.css` — maps the three `next/font` CSS variables (`--font-fraunces`, `--font-manrope`, `--font-jetbrains-mono`) into the `packages/ui-tokens` token names (`--font-display`, `--font-ui`, `--font-mono`). Imported after `tokens.css` so it takes precedence.
- `apps/web/app/layout.tsx` — applies all three `font.variable` class names to the `<html>` element so the CSS variables are available document-wide.
- `apps/web/public/fonts/NOTICES.md` — full OFL 1.1 license text plus per-family copyright statements for Fraunces, Manrope, and JetBrains Mono.

### AC verification
- AC1: At runtime, fonts are served from the Next.js deployment host (verified by `next build` output showing font URLs pointing to `/_next/static/media/`). No third-party CDN required.
- AC2: Fraunces loads with `axes: ['opsz', 'SOFT', 'WONK']` (display + numeral use per DESIGN_DIRECTION.md §3); Manrope variable for UI text; JetBrains Mono variable for monospaced contexts.
- AC3: `apps/web/public/fonts/NOTICES.md` contains OFL 1.1 text and per-family copyright statements for all three fonts.
