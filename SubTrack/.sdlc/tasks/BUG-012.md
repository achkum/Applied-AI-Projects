## Goal

Declare the Playwright CLI as a direct UI package development dependency so the existing CI command does not rely on a transitive Storybook test-runner dependency or incidental executable hoisting.

## Context

- CI step: `pnpm --filter @subtrack/ui exec playwright install chromium --with-deps`.
- The UI package did not declare Playwright directly, and `packages/ui/node_modules/.bin/playwright` was absent in the inspected workspace.
- The lockfile already contains `playwright@1.63.0` (Apache-2.0, Node >=20) as a transitive package of `@storybook/test-runner`; no new package artifact or dependency version is required.
- The CI step annotation reports only a generic exit code 1. Attempting to fetch the GitHub job log artifact from `productionresultssa1.blob.core.windows.net` returned HTTP 403; this is a log-access failure, not evidence about the Playwright browser download. The underlying step stdout and browser HTTP status are unavailable.

## Acceptance criteria

- AC1: `packages/ui/package.json` declares exact development dependency `playwright: 1.63.0`, matching the already locked transitive package.
- AC2: The lockfile change is limited to the `packages/ui` importer entry; package resolution/integrity entries and unrelated importers remain unchanged.
- AC3: The installed cached Playwright CLI reports version 1.63.0 and its `install chromium --dry-run` command resolves the expected browser artifact URLs without downloading them.
- AC4: After a normal frozen workspace install, `pnpm --filter @subtrack/ui exec playwright --version` resolves from the UI package and the unchanged Chromium installation gate is runnable. Do not skip the gate, replace it with `npx`, weaken CI, or use an unpinned version.
- AC5: Keep the GitHub log-artifact HTTP 403 separate from the Playwright step result. The underlying CI failure cause and any browser HTTP status are unconfirmed; do not claim that the direct dependency fixes the CI exit without the full gate.

## Test plan

- Inspect the direct dependency graph and package-local executable path.
- Run the cached CLI `--version` and `install chromium --dry-run` commands without network downloads.
- Verify the UI lock importer pins the exact direct dependency; use CI's clean frozen install to verify the package-local command after linking.
- Re-run the unchanged CI gate and retain the exact Playwright step output if it is accessible; do not infer its cause from the log-fetch error.

## Progress

- 2026-10-04 UTC: Added exact `playwright: 1.63.0` UI devDependency and only the matching `packages/ui` lock importer entry. Cached package metadata confirms Playwright 1.63.0, Apache-2.0, Node >=20, and `bin.playwright = cli.js`.
- 2026-10-04 UTC: Direct cached CLI proof passed: `node node_modules/.pnpm/playwright@1.63.0/node_modules/playwright/cli.js --version` → `Version 1.63.0`; `install chromium --dry-run` printed the expected Chrome for Testing, FFmpeg, and headless shell URLs without downloading. The inspected pre-install workspace lacked `packages/ui/node_modules/.bin/playwright`, so the package-local shim cannot be verified until a normal frozen install.
- 2026-10-04 UTC: `install chromium --with-deps --dry-run` was attempted and failed during apt's dependency simulation because the environment cannot read `/etc/apt/apt.conf.d/80-applied-apt-retries` and several distro packages are unavailable. This does not indicate a Playwright package/CLI resolution failure. No install or browser download was run.
- 2026-10-04 UTC: Evidence correction: the HTTP 403 was returned while fetching the GitHub job log artifact from `productionresultssa1.blob.core.windows.net`. The CI annotation itself only reports exit code 1. No underlying Playwright stdout or browser HTTP status is available; the actual CI cause remains unknown.
- 2026-10-04 UTC: Conductor reports a clean frozen install and CI tests passed. The unchanged Playwright browser-install workflow step still reports generic exit code 1; its stdout is not accessible. This confirms no cause and is not treated as proof that the new direct declaration fixed the gate.
