## Goal and boundary
Deliver an opt-in, fully localized semantic Orbit list and persistent list-mode control using exact host-supplied display strings. Existing callers that omit the new presentation map keep their current DOM, SVG keyboard behavior, callback semantics, geometry and stories unchanged. An opted-in caller must supply complete valid data; invalid data fails deterministically before rendering. This child does not implement or claim 44px SVG hit-target sizing, dense/viewport fallback, ST-025 cost/cadence geometry conformance, quick-split, Home composition or full ST-025 completion.

## Minimal additive component contract
Add optional `locale?: Locale` and `presentationById?: Readonly<Record<string, OrbitPresentation>>` to `OrbitProps`. `OrbitPresentation` contains exactly four required, nonblank host-supplied strings: `categoryLabel`, exact localized monthly-equivalent `amountLabel`, `cadenceLabel`, and `ownerLabel`. Export the type through the existing barrel. `amountLabel` is rendered byte-for-byte. Orbit must not divide/convert `monthlyCostMinor`, multiply annual amounts, infer currency, translate enums itself, or otherwise format/calculate money.

When the presentation map is omitted, preserve the current legacy behavior exactly and make no new complete-list accessibility claim for that path. When supplied, require a valid locale and a complete nonblank presentation record for each subscription ID before rendering; missing locale/entry/field fails with one documented deterministic pre-render validation error. Ignore extra map entries. Preserve stable IDs and input ordering.

Because enriched Orbit reads catalogs at runtime, move the existing `@subtrack/i18n: workspace:*` edge from UI `devDependencies` to UI `dependencies`; do not change its version, add any other dependency, or update unrelated lock records. Root owns the manifest edit, normal pinned-pnpm lockfile generation, semantic review, and frozen-lockfile verification/install. Include these two dependency files in scope.

Append one minimal additive section to `docs/design/components/orbit.md` documenting this opt-in map, legacy omission and validation behavior, host-owned presentation strings, and enriched-list keyboard/AT semantics. Do not rewrite existing geometry, scope, cadence, 44px SVG target, or quick-split requirements.

## Enriched-mode behavior
- For the controls, add the exact catalog keys `orbit.viewAsList` (en `View as list`, sv `Visa som lista`) and `orbit.listLabel` (en `Subscriptions`, sv `Prenumerationer`). Use existing `orbit.ariaLabel`, `orbit.centreMeLabel`, and `orbit.billingCadence.MONTHLY/ANNUAL` entries for enriched mode. The center label is localized. No copy is hardcoded in enriched mode.
- The visible list-mode button retains the stable localized name `View as list` / `Visa som lista`; `aria-pressed` reflects selected list mode. When a keyboard-focused list row is reached from Orbit mode, switch to list mode so the row is visible and the same button becomes pressed. List remains visible after focus leaves; do not temporarily reveal then hide it.
- Render a named region and semantic list with one row button per input subscription, preserving order. Each row shows subscription name, supplied localized category label, exact supplied amount label, cadence label, owner label, and selected state from `activeId`. Row activation calls the existing `onBodySelect` once with exactly that stable ID. Mode control and list-row hit area height are at least 44 CSS px.
- In enriched mode the SVG is `aria-hidden`; body targets are pointer-only, with no tab stops or duplicate button roles. Pointer hits still call the existing selection callback with the same ID. The semantic list is the only keyboard and AT selection representation.
- Initialize enriched list-mode state from the current `prefers-reduced-motion` media preference on first client render; reduced motion starts with a visible list and Orbit animation does not start. If preference changes to reduce at runtime, enter list mode without losing/changing `activeId`. When it changes back, preserve the user's current list/orbit choice. Keep CSS motion freezing in place.
- Keep all body/ring geometry, cost/cadence inputs, ownership mapping, active styling, category-color mapping, empty constellation and callback behavior unchanged. Do not add automatic geometry-based fallback or any ScopeSwitcher/Home changes.
