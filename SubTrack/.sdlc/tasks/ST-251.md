## Required behavior and validation

Read authenticated owner pages through the terminal cursor before claiming a
complete search; reject duplicate IDs/cursor cycles and cancelled/stale results.
Keep sandbox MANUAL/SEK/alwaysPrivate checks on every page. Search displayed names
and accepted localized categories with Unicode/case handling, clear and bilingual
no-match states. Preserve all row actions and reread the complete owner list after
mutations. Blur/logout/new-session invalidation must clear owned search/data.

Group recognized categories with an explicit fallback. Sum ACTIVE expected amounts
only, separately for every currency and saved cadence. Label per-cycle expected
subtotals; do not normalize monthly/yearly, infer Paid, convert currency or use
floating arithmetic. Keep inactive rows visible and editable. Reuse approved
native tokens/fonts/icons and accessibility; do not alter deferred web design.

Meaningful focused tests cover a second-page hit, cursor/ID cycles, stale abort,
Unicode/no-match/clear, large exact sums, mixed currency/cadence, inactive exclusion
and regrouping/subtotal changes following successful persistent reread. Run native
typecheck, targeted tests, i18n parity and appropriate integrated checks once. An
actual signed update and installed Android/iOS behavior remain acceptance gates.
No spending, new accounts, real delivery or production/store release is authorized.
