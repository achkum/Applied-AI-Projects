## Goal
Provide the shared Swedish and English catalog structure and a deterministic parity checker that consumers can run locally and in CI.
## Context (read before starting)

## Acceptance criteria
- AC1: Given the Swedish and English catalog files have identical nested keys, when the parity checker runs, then it exits 0.
- AC2: Given a key exists in only one locale or a nested value has an incompatible shape, when the parity checker runs, then it exits nonzero and identifies the missing/mismatched key path.
- AC3: Given catalogs contain representative shared shell terms, when consumers import the package entry point, then both locale catalogs are available without app-specific duplication.
