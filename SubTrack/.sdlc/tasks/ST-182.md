Implement only an unwired development/test session issuer and bounded in-memory repository, composing accepted ProofStore.consumeLogin and V2AccessToken.issue. Read ADR-0010 and OpenAPI SessionRequest; this is not an HTTP contract or client-ready exchange.

Boundary submitted for independent preimplementation approval:
1. Explicit constructor environment=development and enabled=true, server-owned proof/token/repository dependencies and clock. No env reads, Nest/module/barrel, HTTP, DB/schema, v1 edit, provider, account creation or deployment. Constructor snapshots own enumerable data fields; reject accessor/symbol/hidden/extra/nonplain inputs, generic errors. Dependencies are trusted internal seams, not caller JSON.
2. issueFromLoginProof(input) takes ONLY loginProof, transportContext, optional deviceName. Snapshot input and context before invoking collaborators. Exact mobile context transport only; web exact HTTPS origin/browserChainId. Optional deviceName only mobile string <=100 Unicode codepoints; web forbids it. No caller identity/challenge/session/family/action. Validate strict v2 proof syntax and safe nonnegative integer millisecond clock before consumption. Frozen validated context passed once to consumeLogin; invalid/generic proof outcome creates no session.
3. Identity exclusively canonical lowercase UUID from successful proof. Generate UUID sessionId and familyId, generation=0, random32byte refreshToken with distinct prefix v2r. and canonical base64url. Store ONLY SHA256('subtrack:auth-refresh:v2:'+refreshToken), never raw proof/token/access credentials. Record includes identityId,sessionId,familyId,generation,refreshTokenHash,transport,exactOrigin/browserChainId only web, nullable deviceName, createdAt,expiresAt. Fixed24hour development-reference record lifetime (not production refresh policy), safe timestamp arithmetic. Frozen return ONLY sessionId/accessToken/refreshToken. Verify accessToken returned by trusted issuer is a nonempty bounded string, no logging/details.
4. Repository createForActiveIdentity(record, Readonly<RequestContext>): boolean|Promise<boolean>. Context {userId} derived only from consumed identity, frozen. Atomic validate active registered identity+insert with no await in memory; no separate stale lookup. Memory constructor copies a bounded server-owned list of canonical registered active identity IDs; cannot create identities or re-enable deleted ones. Test/reference markIdentityDeleted(id,context) only matching owner, removes identity and its sessions. Cap active identities and sessions at10000; optional test maxSessions1..10000, constructor validates/copies inputs. Prune expired session records before capacity checks. Reject malformed/corrupt records, scope mismatch, duplicate session/family/refreshhash, future/expired/wrong24h TTL and transport metadata. Store immutable copies.
5. Repository rollbackCreatedSession(expectedRecord,context): boolean|Promise<boolean> compares identity/session/family/refreshhash against the exact new insertion before deleting (no unrelated rows). Issuer calls rollback for failed/throwing/ambiguous create or access-token issuance failure. Generic failure even if rollback fails; never emit credentials on failure. Replay of consumed proof remains burned; no retry. No orphan can live beyond bounded24h reference expiry. Successful issue does not prove current session ownership after commit; later requests require a separately reviewed current v2 principal resolver.
6. In-memory owner-scoped readSession(sessionId,context,now) returns frozen copy or null, requires current active identity and unexpired record; never unscoped row access. Internal reference/test only, no listing/revocation/refresh rotation APIs. No durable/multi-process atomicity claim.
7. Tests actual ST178 simulator producer -> ProofStore -> issuer -> V2AccessToken verifier web/mobile, expected identity/sid/TTL/transport/hash; replay/concurrent one winner. Deletion between consumed proof and atomic create rejects. Wrong origin/chain/transport/restricted proof, extra/accessor/symbol/hidden identity selectors rejected before deps. Inactive/malformed identity, record/scope/capacity/collision/expiry corruption, store/token errors and exact owner/family/hash rollback preserving unrelated sessions, rollback failure no secrets. No raw secrets retained/logged; generated ephemeral keys only. Preserve all existing tests; declared API suite/lint/typecheck/build plus independent exact source hashes, gitleaks and exact-head CI before routine squash merge.
