## Goal
Implement mobile Orbit as a high-performance Skia-accelerated component with full reduced-motion accessibility fallback to semantic list view.

## Context (read before starting)
- docs/product/DESIGN_DIRECTION.md §4 (Orbit), §3 (motion: slow rotation, reduced-motion behavior), §6 (layout)
- docs/governance/QUALITY_GATES.md (test pyramid, accessibility)
- ST-023 component specifications (once DONE)
- `packages/ui-tokens`: category colors (RN theme), reduced-motion value

## Acceptance criteria
- AC1: **Orbit visual (Skia)**: Subscription bodies render as circles in concentric rings using react-native-skia for high-performance rendering; sized by cost, positioned by billing-cadence radius, colored by category; grain texture (2% opacity, off on low-end Android); slow rotation effect (1 revolution per 4 minutes using Reanimated loop)
- AC2: **Touch interaction**: Tap body → shared-element transition to detail view (Expo Router animation); long-press → quick-split sheet modal; bounce haptic on tap; medium haptic on successful action
- AC3: **Reduced-motion fallback**: prefers-reduced-motion:reduce renders semantic FlatList with category badge, price, owner per subscription; list is default mode; no rotation, no transitions (instant state)
- AC4: **Accessibility**: Fallback list is fully navigable via VoiceOver/TalkBack, each item has accessibilityLabel (subscription name + price + owner), accessibilityRole="link"; screen reader announces list mode default and optional visual mode
- AC5: **Performance**: Rendering target 60 fps on mid-range Android (e.g., Pixel 4a) and iOS (iPhone 12+); Maestro performance profiling or React DevTools Profiler benchmark included in PR
- AC6: **Motion language**: Reanimated spring (damping: 18, stiffness: 180); reduced-motion disables all animation; tested on iOS Simulator with accessibility settings and real Android device
- AC7: **Test coverage**: Vitest unit tests (orbit math: radius, angle, sizing); Maestro E2E (iOS sim + Android emu) for tap/long-press/nav; VoiceOver/TalkBack validation (at least one screen reader); visual snapshot (light/dark, motion on/off)
- AC8: i18n: body labels and list headings use i18n context keys; sv and en parity verified

## Out of scope

## Technical notes
- react-native-skia version pinned and verified for stability on both platforms
- Reanimated rotation loop: use runOnJS with Animated.loop for continuous rotation; pause on reduced-motion
- Long-press: Gesture Handler LongPressGesture with 400ms delay
- Shared-element transition: Expo Router animation + `sharedTransitionTag` or manual Reanimated layout animation
- Fallback list uses FlatList with keyExtractor; renderItem shows subscription card with category badge
- Do not edit CI workflows; Maestro suite wiring is ST-017 and QA scope
