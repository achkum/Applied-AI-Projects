Deliver shared Norrsken design tokens and deterministic web/native outputs, category hue generation, and automated contrast validation.

## Acceptance criteria
- AC1: Given the token source is unchanged, when the generation command runs twice, then CSS variables and the React Native theme output are deterministic and the second run leaves no diff.
- AC2: Given the token source is generated, when compared with DESIGN_DIRECTION.md §3, then it includes the named light/dark color roles, typography scale, radii, and motion defaults with both theme values where specified.
- AC3: Given the 22 category hues are generated, when output is checked, then there are exactly 22 stable category assignments on the prescribed OKLCH wheel and rerunning with the same input produces identical output.
- AC4: Given every declared foreground/background token pair is checked, when contrast validation runs, then all text pairs meet WCAG AA or the command exits nonzero identifying the failing token pair; CI wiring is tracked by ST-016.
