## Goal
Repair the current mobile lint, strict typecheck, and Orbit component test failures while preserving the existing reduced-motion, accessible-list, and signature-component behavior.

## Context (read before starting)
- The full check reports Orbit tests crashing because the test mock for `react-native-reanimated` does not provide the `useReducedMotion` function consumed by `useOrbitRotation`.
- Strict typecheck reports optional prop mismatches (`activeId`, `onPress`) and unchecked layout/test array access in Orbit.
- ESLint reports forbidden `require()` imports in Orbit and signature component tests, plus an unused eslint-disable directive in `test/tsx-fixture.tsx`.
- The output includes 5 failing tests and 7 lint errors; previous canceled command logs are not additional defects.

## Acceptance criteria
- AC1: Jest's Reanimated mock provides deterministic `useReducedMotion` behavior for Orbit tests and can exercise both reduced-motion and normal-motion paths without changing production behavior.
- AC2: Orbit and related tests/components pass strict TypeScript checks with `exactOptionalPropertyTypes` and `noUncheckedIndexedAccess` unchanged. Optional props are omitted or handled intentionally; array access is guarded rather than asserted unsafely.
- AC3: Replace forbidden `require()`-style imports in the scoped tests/config with valid imports or supported Jest mock patterns, preserving test behavior and coverage.
- AC4: Remove the unused eslint-disable directive and fix all scoped lint errors without rule suppression.
- AC5: Existing assertions for Orbit visual/list fallback, member/body interaction, reduced-motion behavior, and signature components remain present and pass; no test is deleted, skipped, or weakened.
- AC6: `pnpm --filter @subtrack/mobile lint`, `typecheck`, and `test` pass.
- AC7: No visual redesign or intended product behavior change is introduced. A visible behavior change requires a recorded design-lead review before merge.

## Out of scope
- Replacing the mobile component-render test harness or changing React Native/RNTL versions.
- Redesigning Orbit or signature components, changing tokens/copy/navigation, or changing shared UI/web behavior.
- Weakening TypeScript settings, suppressing ESLint, or removing failing tests.

## Technical notes
- Keep test-only motion behavior in Jest setup/mocks and keep production reduced-motion behavior accessible to users.
- Use conditional prop spreads or explicit branch handling compatible with exact optional property types; do not pass `undefined` as an optional value unless the type explicitly permits it.
- Any new development type package must be scoped to this app and reflected in the lockfile; no dependency is expected for these fixes.

## Test plan
- Run the mobile lint, typecheck, and full Jest suite.
- Confirm the reduced-motion mock supports both true and false cases and all prior Orbit/signature assertions still execute.
- Record exact command results in handoff.
