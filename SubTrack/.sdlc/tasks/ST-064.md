## Goal
Provide a human-readable YAML seed catalogue of ~60 merchants and ~120 subscription plans, with TypeScript types and a loader, enabling the database to be seeded with real-world Swedish-market subscription data and enabling integration tests.

## Context
- ST-060 created the `merchant` and `catalogue_plan` tables in Postgres
- ST-067 (ingestion) and ST-080 (detection) will use the merchant catalogue to normalise detected subscriptions
- PRODUCT_SPEC §F1: merchant catalogue must cover the subscription categories defined in categories.json
- All amounts are in SEK öre (minor units)

## Acceptance criteria
- AC1: `data/merchants.yaml` contains ≥ 60 merchants, each with `canonical_name`, `aliases[]`, `category`, `category_hue`, and optional `website`.
- AC2: `data/plans.yaml` contains ≥ 120 plan entries, each with `merchant_key`, `name`, `period` (MONTHLY/ANNUAL/QUARTERLY), `amount_minor`, `currency`, `region`, `active`.
- AC3: TypeScript types `CatalogMerchant` and `CatalogPlan` match the DB schema (`merchant` and `catalogue_plan` tables from ST-060 migration).
- AC4: `loadCatalog()` exported from `@subtrack/catalog` reads and validates both YAML files; throws on malformed entries.
- AC5: `pnpm --filter @subtrack/catalog test` passes — validates counts, required fields, merchant_key cross-references, and no duplicate canonical_name values.
- AC6: All category values in merchants.yaml are from `packages/ui-tokens/src/categories.json` (SCREAMING_SNAKE_CASE).

## Out of scope
- Database seeding script (that is a separate migration or seeding task).
- Forex conversion or dynamic pricing APIs.
- Merchant logo assets.

## Technical notes
- `js-yaml` used for YAML parsing; read synchronously at module load (catalog data is static).
- `category_hue` is an OKLCH hue (0–360) matching the ui-tokens category color wheel.
- `merchant_key` in plans.yaml is a stable slug identifier; NOT stored in DB (DB uses UUID).
- NodeNext module resolution: imports use `.js` extensions.

## Verification evidence
- `pnpm --filter @subtrack/catalog test` — all tests pass.
- `node -e "import('@subtrack/catalog').then(m => console.log(m.loadCatalog().merchants.length))"` logs ≥ 60.

## Progress
- 2026-10-01 UTC: Implemented. data/merchants.yaml (62 merchants), data/plans.yaml (124 plans), src/types.ts + src/loader.ts + src/index.ts. Tests validate counts and structure.
