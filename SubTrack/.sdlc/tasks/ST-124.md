## Goal

Add subscription-vs-not and category classifiers to `services/ml`, exposed via `POST /ml/v1/classify`.

## Acceptance criteria

- [x] `app/catalog.py` loads `packages/catalog/data/merchants.yaml` and exposes `get_alias_category_pairs()` and `get_canonical_names()`
- [x] `SubscriptionClassifier` — two-stage: exact/partial alias match → TF-IDF+LR fallback
- [x] `CategoryClassifier` — TF-IDF char_wb ngram (3,5) + LogisticRegression
- [x] `app/classifiers/registry.py` — lazy singletons `get_subscription_clf()`, `get_category_clf()`
- [x] `POST /ml/v1/classify` returns `{subscription, category|null}`; category only when `is_subscription=true`
- [x] `GET /ml/v1/models` lists both classifiers
- [x] 25 tests pass (`tests/test_classifiers.py` + updated `tests/test_endpoints.py`)
- [x] `docs/model-card-classifiers.md` written
- [x] `pyproject.toml` updated: scikit-learn>=1.5, numpy>=2.0, pyyaml>=6.0, joblib>=1.4

## Implementation notes

- Training data: all `aliases` + `canonical_name` from merchants.yaml (~350+ labeled examples)
- Negatives: 31 hand-curated non-subscription bank descriptors (groceries, ATM, restaurants)
- `multi_class` param removed — deprecated/removed in scikit-learn 1.5; `lbfgs` handles multiclass natively
- Catalog path: `parents[3]` from `app/catalog.py` resolves to `SubTrack/` root, then `packages/catalog/data/`
