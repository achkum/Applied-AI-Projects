Raw nonce/idempotency headers must each occur once; recognized binding-cookie duplicates rejected through current transport middleware. Complete idempotency settlement BEFORE nonce/challenge/proof HTTP fields or code-sink availability. Failure burns reservation/nonce as applicable, no secret replay. Duplicates or uncertain committed operations return generic409 AUTH_RESTART_REQUIRED; validation/binding failures generic, cache no-store/no-cache.

Prune expired records and rejectcapacity before unbounded allocation. Test harness can inspect injected sink internally. Proof remains enrollment or stepup and cannot login/select identity. Unknown challenge responses reveal no account state.

Actual Nest registered HTTP/HTTPS test full flow via injected sink: bootstrap nonce/cookie, OTPstart rotates nonce, verify rotates nonce and returns restricted one-use proof.
