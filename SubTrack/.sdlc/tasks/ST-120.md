## Goal
Implement `@subtrack/llm-gateway`: provider adapters for Gemini, Groq, OpenRouter (free-only), and Template; in-memory LRU cache with TTL; per-provider token-bucket rate limiter; numeric post-check for LLM output validation.

## Acceptance criteria
- AC1: All 4 providers implement the `LlmAdapter` interface.
- AC2: `OpenRouterProvider` throws on any model without a `:free` suffix (enforced in code, not config).
- AC3: `LlmCache` provides LRU eviction and TTL expiry (configurable).
- AC4: `RateLimiter` uses a token-bucket algorithm per provider with independent buckets.
- AC5: `checkNumericOutput` detects NaN/Infinity text, large numbers, and 16+-digit integers.
- AC6: All tests pass without real API keys (TemplateProvider + unit tests).

## Technical notes
- OpenRouter `:free`-only constraint is HARD — no config toggle, throw at call time.
- Dynamic imports used in Gemini/Groq providers to avoid loading SDKs when not in use.
- `LlmGateway` composes cache, rate-limiter, and adapters; `register()` allows test injection.

## HANDOFF/v1
- `LlmGateway` — `packages/llm-gateway/src/gateway.ts`
- 4 providers — `packages/llm-gateway/src/providers/`

- 38 tests across 4 files (`template-provider`, `numeric-check`, `cache`, `rate-limiter`), all passing
- OpenRouter `:free` enforcement is code-level (not config-level)
