## Goal and evidence
Normal Prisma 6.19.2 generation now succeeds using official checksum-verified binaries. The API typecheck reveals strict indexed mock-call accesses, a recursive mock transaction annotation, optional invitation token serialization, and a Session model absent from schema despite the already accepted `0003_session` migration and SessionsService.

## Acceptance criteria
1. Preserve every existing assertion and strict flag; fix mock-call access with explicit runtime guards/assertions and valid mock typing, without `any`, blanket non-null assertions or suppression.
2. Omit absent optional invitation token rather than emit undefined; preserve all supported channels and authentication/privacy behavior.
3. Before adding a Session model, independent architect-platform/security review must verify exact parity with accepted 0003_session SQL, DATA_MODEL, and current session service. No new or rewritten migration; no database writes. Restore schema representation of already approved table only if reviewed.
4. Normal Prisma generation, API lint/typecheck/tests pass; retain session ownership, refresh reuse, revocation, invitation/privacy coverage.
5. Independent review and QA approve, then required CI before merge.

## Dispatch
Conductor main; developer Luna. Diagnose log `/workspace/.setup/subtrack-api-typecheck-final.log`; normal API tests `/workspace/.setup/subtrack-api-tests-final.log`.
