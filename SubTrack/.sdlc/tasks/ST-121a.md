## Goal and context
Deliver a runnable local-file catalogue extraction pipeline for ST-121, PRODUCT_SPEC F8.5 and AI_ML_SPEC section 4. Captured inputs produce candidate observations and quarantine artifacts, never verified market prices. Accepted catalogue/gateway dependencies exist on main e6f305a. No existing ST-121 implementation or open PR was found.

## Architecture decision
Adopt ADR-0019 before implementation. Candidate official sources Storytel and BookBeat remain live-disabled: robots observations do not settle terms permission. Own synthetic HTML snippets exercise configurable text-anchor/DOM extraction; they must be labeled synthetic rather than represented as captures of actual current page markup. Use catalogue-owned pinned Playwright and tsx dependencies and workspace Money. Chromium uses an isolated context, blocks all requests, and disables page scripts. No network fetching, source approval flag, browser cookies, persistent browser profile or existing database is accepted.

## Acceptance criteria
- AC1: A documented command accepts a strictly bounded local JSON manifest naming registered sources, local HTML inputs, explicit synthetic/manual-fixture provenance, ISO capture time and optional previous canonical SEK minor-unit strings. Validate exact fields, identifiers and bounds; no arbitrary source URL or claim of live verification.
- AC2: Registered source extraction uses Playwright DOM selectors/text anchors, requires unambiguous named base plans and whole SEK monthly price tokens, rejects promotions/from/add-ons/duplicates/changed markup. No LLM or invented current-price assertion.
- AC3: Candidate JSON includes source URL, extraction version, input SHA256, capture timestamp/mode and SEK minor units serialized as decimal strings. Exact Money comparisons quarantine missing baseline and absolute changes strictly greater than 40%; exactly 40% is allowed. Schema/extraction failures never produce partial accepted observations for a source.
- AC4: The command writes only its explicitly named output file and closes browser/context on success/failure. Input HTML cannot make network requests, execute scripts or access another file. No credentials/HTML contents are logged. Live crawling is absent and registry entries explicitly disabled with unresolved terms decisions.
- AC5: Meaningful tests cover both registered source fixtures, invalid manifests/prices/ambiguity/markup, 40% boundary and no baseline, network/script isolation and command execution through the real browser. CLI output must be proven end to end. Catalogue lint/typecheck/test and required exact-head CI pass with independent source/security review and QA.
