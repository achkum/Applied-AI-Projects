## Goal
Add public formatMinorUnits(bigint, currencyCode, options) with exact integer arithmetic. Preserve existing formatMoney(number) API and tests unchanged. This is the shared formatter prerequisite for mobile demo; no caller migration or native runtime claim.
## Architecture
Validated advisory design /workspace/.setup/bigint-formatter-proposed-contract.md. Currency exponent from existing Intl metadata guard; quotient/remainder bigint; currency template and localized integer/fraction parts. Preserve grouping, sign (including negative below-unit values), decimal separators, literals and currency placement. No Number conversion, floating money arithmetic or hardcoded currency exponent. Currency names excluded because plural behavior is unverified.
## Acceptance

Reject non-bigint amount without interpolating it into error. Preserve native invalid currency RangeError and existing metadata guard message.
Exact tests defaults/bothlocales, symbol/code/narrowSymbol, SEK/JPY/KWD, positive/negative/zero/negative subunits, grouping and amounts above safe integer range; invalidcurrency/options/amount/metadata.
