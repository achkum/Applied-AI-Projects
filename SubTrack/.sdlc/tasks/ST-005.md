## Goal
Run the M0 repository quality checks in CI only when SubTrack files change, while preserving unrelated repository workflows.
## Context (read before starting)
- BACKLOG_SEED.md ST-005
- ROADMAP.md §M0
- QUALITY_GATES.md
- ADR-0001

## Acceptance criteria
- AC1: Given a pull request changes a path under `SubTrack/`, when the workflow runs, then lint, typecheck, tests, i18n parity, gitleaks secret scanning, and license checking are each represented by a visible required job/step and a failure makes the workflow fail.
- AC2: Given a pull request changes only paths outside `SubTrack/`, when workflow path filters are evaluated, then this SubTrack workflow is not scheduled.
- AC3: Given any checker reports a nonzero result, when CI completes, then the workflow is red and exposes the failing checker output without printing secrets.
