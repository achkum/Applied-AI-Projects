## Acceptance criteria
- AC1: Given Docker Compose is installed and the repository root is the working directory, when `make up` completes, then PostgreSQL 16, Redis, Mailpit, and Caddy containers are started and each declares a healthcheck whose healthy state is observable with `docker compose ps`.
- AC2: Given the stack is running, when `make logs` is invoked, then logs for the stack are followed; when `make down` is invoked, then stack containers are stopped and removed without deleting named volumes.
- AC3: Given the stack is running and the seed target is documented, when `make seed` is invoked, then it runs the declared local seed command and exits nonzero on failure; no production credentials or non-local ports are required.
