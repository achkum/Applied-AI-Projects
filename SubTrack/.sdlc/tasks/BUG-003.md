## Goal
Remove the test-only dependency cycle in the workspace by colocating ingestion integration tests with the synthetic package that supplies their test data, while preserving all existing test coverage and public package behavior.

## Context (read before starting)
- `packages/domain` currently has `@subtrack/synthetic` as a devDependency so `packages/domain/test/ingestion.spec.ts` can use `SyntheticBankProvider`.
- `packages/synthetic` has a runtime dependency on `@subtrack/domain` because its provider implements the domain bank interface. Together these edges create a workspace cycle that causes `pnpm check` to exit before task checks run.
- The existing ingestion spec contains 24 tests. It can live under `packages/synthetic/test/` and import `@subtrack/domain/ingestion` through the exported package path.
- Conductor requires architect-platform review before implementation because this changes package test ownership/dependency direction. Reviewer approval of the relocation approach is a pre-implementation gate.

## Acceptance criteria
- AC1: Architect-platform records approval of the test relocation and confirms the domain-to-synthetic devDependency can be removed without changing runtime architecture before implementation begins. If the review finds a package-boundary conflict, return BLOCKED without changing manifests.
- AC2: All 24 existing ingestion test cases are preserved in `packages/synthetic/test/ingestion.spec.ts`; no test is deleted, skipped, or weakened.
- AC3: The relocated tests import domain ingestion through `@subtrack/domain/ingestion` and use the local synthetic package provider as test data.
- AC4: Remove the `@subtrack/synthetic` devDependency from `packages/domain/package.json`; preserve the synthetic package's existing runtime dependency on domain.
- AC5: Update `pnpm-lock.yaml` only if needed to reflect the manifest change. No unrelated dependency/version changes.
- AC6: `pnpm --filter @subtrack/domain test`, `pnpm --filter @subtrack/domain typecheck`, `pnpm --filter @subtrack/synthetic test`, `pnpm --filter @subtrack/synthetic typecheck`, and `pnpm check` run to completion; report any unrelated failing checks without hiding them.

## Out of scope
- Changing ingestion implementation or semantics, provider interfaces, domain runtime dependencies, or package boundaries.
- Deleting tests, reducing assertions, changing test runner configuration except as required for the relocated file to run.

## Technical notes
- The synthetic Vitest configuration already includes `test/**/*.spec.ts`; use the existing test runner.
- Tests should continue to verify normalization, deduplication, update/idempotency, per-account isolation, and the complete ingestion worker lifecycle.
- Keep all changes within allowed_paths. Do not change the board.
