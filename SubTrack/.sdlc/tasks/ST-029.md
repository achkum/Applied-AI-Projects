## Goal
Create app icon, splash screen, and store feature graphic concepts using Norrsken design language (aurora-lit orbit on ink, minimal line-art constellations, editorial serif numerals).

## Context (read before starting)
- docs/product/DESIGN_DIRECTION.md §5 (Brand moments: app icon aurora-lit orbit, splash bodies fly in, empty states use constellations) + §3 (Foundations: colors, typography)
- ST-020 token system (colors, aurora gradient, typography definitions)
- Apple App Store listing requirements (iOS 5.1 guidelines)
- Google Play Store listing requirements (Android guidelines)
- docs/governance/QUALITY_GATES.md

## Acceptance criteria
- AC1: **App icon concept**: Aurora-lit orbit ring (3 tinted bodies or dots) on ink background, reads well at 180×180, 120×120, 60×60px (home screen, search, notification sizes); iOS tinted-icon mode compatible (monochrome); Android adaptive icon (safe zone); concept in 2+ color variations (dark default + light mode if applicable)
- AC2: **Splash screen**: Aurora slowly forms the SubTrack wordmark; bodies fly in one-by-one as detected; minimal line-art constellations (never stock art) on background; sv: "Allt ni prenumererar på. På ett ställe." / en: "Everything you subscribe to. In one place." with Manrope medium weight; animation spec (timing, easing) documented
- AC3: **Store feature graphics**: 
  - QUESTION/v1a: iOS App Store (1242×1242 or 3:4 aspect, feature image for listing)—dimensions confirmed via Apple App Store Connect docs, format (PNG/JPG), no text overlay if auto-generated required
  - QUESTION/v1b: Android Play Store (1080×1920 or 9:16, feature image for listing)—dimensions confirmed via Google Play Console docs, format, localization requirements (sv/en separate assets or single)
  - QUESTION/v1c: Are app widget icons needed for Android? If yes, dimensions and priority vs. core icon?
  - Concepts created per confirmed platform requirements, using Norrsken visual language (aurora gradient, orbit theme, constellation accents)
- AC4: **Visual guidelines**: Style guide document published (colors used from ST-020 tokens, typography refs, motion specs if animated); concept assets linked in document
- AC5: **Accessibility**: High-contrast icon visible at small sizes; no critical info in icon alone (text+icon together); store descriptions are accessible (separate from graphics)
- AC6: **i18n** (graphics): Splash and store graphics are imagery-based; if text is embedded, sv and en versions created as separate assets or verified to work bilingually
