## Goal
Deliver identityprovider interface and bankid simulator in scope of SubTrack PRODUCT_SPEC, with privacy and security invariants enforced.
## Context
- PRODUCT_SPEC §F1.2; USER_FLOWS.md UF-01 step 4; DATA_MODEL.md §Identity; ADR-0003
## Acceptance criteria
- AC1: Given simulator mode and one of the fixed demo identities, when the demo flow is signed, then provider returns a deterministic verified identity without contacting BankID.
- AC2: Given an identity result, when persisted, then only method, name, verification time, and keyed HMAC of personnummer are stored; raw personnummer is never persisted or logged.
- AC3: Given a repeated HMAC, when registration completes, then return the defined existing-account/login response rather than creating a duplicate.

## Handoff — v1

### What was built
- `apps/api/src/auth/identity-provider/identity-provider.interface.ts` — `IdentityProvider` interface + `IdentityResult` type + `IDENTITY_PROVIDER` DI token
- `apps/api/src/auth/identity-provider/bankid-simulator.ts` — `BankIdSimulator`: 3 fixed demo identities (alice/bob/carol), deterministic HMAC-SHA256(personnummer, secret), no external calls (AC1)
- `apps/api/src/auth/identity-provider/identity-provider.service.ts` — `verifyAndRegister`: verify token → persist (method, externalId=HMAC) → return registered/logged_in; dedup by HMAC (AC3)
- `apps/api/src/auth/identity-provider/identity-provider.controller.ts` — `POST /v1/auth/bankid/verify`
- `apps/api/src/auth/identity-provider/identity-provider.module.ts` — NestJS module; wires `BankIdSimulator` via `IDENTITY_PROVIDER` token; reads `BANKID_HMAC_SECRET` env var
- `apps/api/src/auth/auth.module.ts` — updated to import `IdentityProviderModule`
- `packages/contracts/openapi.yaml` — `POST /v1/auth/bankid/verify` + `VerifyBankIdBody`/`VerifyBankIdResponse` schemas
- `apps/api/src/auth/identity-provider/identity-provider.spec.ts` — 9 vitest unit tests (BankIdSimulator + IdentityProviderService)

### AC verification
- AC1: Simulator returns deterministic verified identity for alice/bob/carol without any network call ✅
- AC2: Only `method`, `externalId` (=HMAC), `authMethod` stored; raw personnummer never in create data ✅ (tested)
- AC3: Repeated HMAC → `logged_in` response, no duplicate row created ✅
