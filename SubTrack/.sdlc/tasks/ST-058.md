## Goal
Implement the three hero screen routes in `apps/web` with mocked data, light/dark theme, and sv/en localization, using the ST-024/ST-025 components and matching the G-DESIGN-approved ST-057 compositions.

## Context
- docs/product/DESIGN_DIRECTION.md §§4–6 (signature components, brand moments, layout)
- docs/design/components/ (component specs from ST-023)
- ST-057 Storybook compositions (G-DESIGN approved reference)
- packages/ui-tokens, packages/i18n
- apps/web uses Next.js 16 with next-intl; routes are under app/[locale]/

## Acceptance criteria
- AC1: **Welcome page** at `app/[locale]/` (or `app/[locale]/welcome/`) — aurora gradient animation; wordmark; sv/en subtitle; light/dark correct; no hydration errors.
- AC2: **Home page** at `app/[locale]/home/` — Orbit (ST-025) with 3–5 mocked subscriptions; Scope switcher (ST-024); Rolling total (ST-024); light/dark; sv/en.
- AC3: **Subscription detail page** at `app/[locale]/subscriptions/[id]/` — ReceiptCard (ST-024) with mocked data; price in Fraunces; category color from tokens; light/dark; sv/en.
- AC4: Theme switching (light/dark) and locale switching (sv/en) work across all three pages.
- AC5: `vitest` component tests verify each page renders without errors in both themes and both locales; no hard-coded hex values; `jest-axe` passes on all three pages.

## Out of scope
- Real API integration — all data is mocked/static.
- Maestro/E2E (ST-039, ST-052).
- Mobile screens (ST-051, ST-055).

- Mocked data shapes must match `packages/contracts` types.
- All locale strings via `packages/i18n`; no raw strings in JSX.
- Reduced-motion: freeze aurora animation when `prefers-reduced-motion: reduce`.
