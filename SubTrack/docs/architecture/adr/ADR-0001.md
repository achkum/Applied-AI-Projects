# ADR-0001: Monorepo with pnpm workspaces + Turborepo inside Applied-AI-Projects/SubTrack

- Status: Accepted (seed ADR, founder may veto per ASSUMPTIONS.md)
- Deciders: architect-platform, Conductor

## Context
The founder wants one repo for now. Many agents need shared types and tokens.

## Decision
pnpm + Turborepo, path-filtered CI. `_legacy/` holds the old prototype until M1 exits.

## Consequences
+ One PR can change the contract, API and clients atomically. − The repo contains unrelated projects, so CI must use path filters.
