# ADR0035 — Isolated public tester sandbox identity

Accepted2026-10-14 by founder reply A to the concrete proposal at .sdlc/evidence/ST-250/sandbox-identity-proposal.md. This is a bounded sandbox-only exception to ADR0010 verified BankID/fresh-login and ADR0006 fixed demo identities. Production requirements remain unchanged.

Each installation receives a server-created synthetic workspace and random256-bit possession credential, native secure-storage only, domain-separated digest in isolated PostgreSQL. No client-selected owner, email/phone verification, shared Alice/Bob or BankID claim. Capability lifetime30days non-sliding; access15minutes and session24hours capped by capability expiry. Resume resolves owner from durable possession, including sandbox-only recovery after uncertain refresh. Refresh remains atomic/one-use; reuse revokes family. Logout atomically revokes workspace capability and all sessions. Restart readback persists before logout; reinstall/lost credential/expiry/logout cannot recover old workspace. Bootstrap returns credentials only after known commit and never replays them after duplicate/uncertain issuance. No destructive compensation.

Separate database, roles, issuer/audience/keys, environment/epoch and app identifiers. Every business operation requires current owner/session and accepted RLS/replay/commit guards. Public link is discovery only. Enforce bounded ingress, global admission/storage and per-owner capacity. Clearly label synthetic/simulated verification; fictional tester inputs. No real providers/OTP, spending, new third-party accounts, production/public store release or OpenClaw software/services/directories.

Founder already authorized zero-cost public-link sandbox hosting on existing VPS. Adoption permits separately reviewed implementation; independent source/security/CI/deployment reviews and actual two-owner/restart/revocation/device evidence still precede public operation. Original private runtime stays development/loopback-only. Full exact security semantics and release evidence are in the adopted proposal; do not quietly reduce them.
