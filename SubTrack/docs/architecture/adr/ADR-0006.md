# ADR-0006: BankID via the official test environment + in-app simulator mode

- Status: Accepted (seed ADR, founder may veto per ASSUMPTIONS.md)
- Deciders: architect-platform, Conductor

## Context
Real BankID production needs a bank agreement. Store reviewers can't use a Swedish test BankID.

## Decision
IdentityProvider with modes `test` (RP API v6.0, public test cert, test BankID from demo.bankid.com) and `simulator` (UI replica, fixed demo identities). The mode is set by env; simulator is never enabled with prod data.

## Consequences
+ Realistic flows plus a reviewable app. − Simulator must be clearly labelled to avoid implying real identity verification.
