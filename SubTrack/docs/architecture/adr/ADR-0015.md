# ADR-0015: Exact advisory converted-cost swing primitive

Status: Accepted locally, 2026-10-09, Conductor acting architect-platform/data/PO after independent arithmetic/contract review.

AI_ML_SPEC section5 includes unexpected FX swing on USD/EUR-billed services. Current source types do not carry original billed amounts/currencies. Add a standalone Money API receiving authoritative caller-supplied billed/settled Money pairs; do not modify provider/source types or claim integrated detection.

Assumed reversible advisory semantics: effective booked conversion cost including markup/fees/rounding; at least four prior eligible pairs and at most50; strict relative drift greater than5% from their ordinary exact-rational median, with threshold equality inside. These choices are heuristics, not specified thresholds or validated statistical confidence. Fewer than four valid references returns false; every pair is still validated. Caller owns provenance, one-owner/service/homogeneous-currency grouping, chronological reference selection, candidate exclusion and posted-debit/refund filtering.

Compare absolute settled/billed minor-unit ratios using reduced bigint fractions. Homogeneous currency exponent scaling cancels from medians and relative drift; no absolute rate is returned. For candidate n/d and median N/D, test20*abs(nD-Nd)>N*d. No float money, rounding or arithmetic outsidepackagesMoney. Fixed MoneyError reports malformed/zero/currency/history/unexpected failures without callerdata.

This additive Type2a API has no consumer/default wiring or automatic financial action. Market FX movement cannot be distinguished from fees without separately trusted rate/fee data. Provider/source/persistence/fullST081ST126 integration remain pending. No DB/schema/dependency/UI/auth/security-model/production changes authorized. Required meaningful golden tests, fullMoney regression/100%newhelperbranchcoverage, independent source review, secret scan and all actual CI steps precede merge.
