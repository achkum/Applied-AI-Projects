# ADR-0003: NestJS + Prisma + PostgreSQL 16 with Row-Level Security

- Status: Accepted (seed ADR, founder may veto per ASSUMPTIONS.md)
- Deciders: architect-platform, Conductor

## Context
Many agents generating backend code need strong conventions. Tenancy must be defence-in-depth.

## Decision
NestJS modules per bounded context (identity, household, banking, subscriptions, money, insights, catalog, notifications). Prisma for schema/migrations. RLS policies in raw SQL migrations.

## Consequences
+ Predictable structure; RLS catches policy bugs. − Prisma + RLS needs per-request transactions (documented pattern in the backend skill).
