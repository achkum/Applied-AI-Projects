# ADR-0004: Expo (React Native) for iOS/Android, Next.js for web; shared tokens, not shared components

- Status: Accepted (seed ADR, founder may veto per ASSUMPTIONS.md)
- Deciders: architect-platform, Conductor

## Context
The founder wants store binaries and a web app. The best native feel comes from separate component layers over shared tokens, domain logic and API client.

## Decision
Expo Router + EAS Build/Submit. Next.js App Router. `packages/ui-tokens` feeds both; `packages/ui` (web) and `packages/ui-native` (mobile) implement components.

## Consequences
+ Native feel, EAS builds without a Mac. − Two component implementations (mitigated by specs + visual tests).
