# ADR-0019: Offline catalogue extraction candidates

Status: Accepted for bounded implementation; final source review and QA required before merge.
Decision class: Type 2a (additive catalogue tooling).
Date: 2026-10-10.

ST-121 needs a working extraction pipeline before scheduled catalogue observation storage. Existing seed prices remain illustrative. Authoritative database inventories and public-source permissions are separate prerequisites.

Implement a manually invoked, local-file-only command in the catalogue package. Catalogue owns pinned Playwright and tsx dependencies and uses workspace Money. An isolated script-disabled browser loads supplied HTML with all network requests blocked. Strict manifests select registered source extractors, explicit synthetic or manual-fixture provenance, capture time and optional previous SEK minor-unit strings. Candidate artifacts record source URL, input checksum and extractor version; they do not claim current or verified market prices. Ambiguity fails closed per source. Missing baselines and absolute price changes greater than40% are quarantined with exact Money operations; exactly40% passes.

Storytel and BookBeat are candidate sources with live fetching disabled. Public robots observations alone do not resolve restrictions in service terms; no permission is inferred. Synthetic fixtures demonstrate our extraction interface, not actual current-page compatibility. No source flag enables networking in this command. Source permissions/current markup, 15-source coverage, browser request scheduling/throttling, LLM fallback, persisted observations and market UI remain ST-121 follow-up requirements.

No default API module, security authority, database, migration, provider, public endpoint or deployment changes. This decision cannot activate live crawling or supersede source terms. Architecture assessment: data_backlog_readiness, retained in ST-121a evidence; independent security review must approve the actual isolation and provenance implementation.
