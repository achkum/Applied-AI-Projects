# ADR-0002: TypeScript everywhere except ML (Python)

- Status: Accepted (seed ADR, founder may veto per ASSUMPTIONS.md)
- Deciders: architect-platform, Conductor

## Context
Web, mobile and API share types. ML libraries are best in Python.

## Decision
TS 5.x strict for apps and packages. Python 3.12 + FastAPI for services/ml, with uv for deps.

## Consequences
+ Maximum sharing. − Two toolchains in CI.
