# ADR-0014: Exact median/MAD amount comparison

Status: Accepted (local additive API architecture), 2026-10-09. Conductor acting as architect-platform/data accepts this reversible Type2a decision after independent arithmetic/contract review APPROVE. No founder Type1 behavior is authorized by this ADR.

AI_ML_SPEC §5 requires flagging amounts outside median ± 3×MAD. Ordinary even-sample medians can be fractional minor units, and monetary arithmetic belongs exclusively in packages/money.

Add a deterministic `isAmountOutsideMedianMad(candidate, history)` Money API. Homogeneous caller-scoped reference history excludes the evaluated candidate and contains 1..1000 canonical bigint Money values. Compute medians and deviations as exact scaled bigint rationals; strict threshold comparison treats equality as inside. MAD=0 is handled by its literal mathematical definition. Validation failures use a fixed MoneyError without caller data.

This reversible additive API has no consumer/default wiring. Caller integration must establish authorization, subscription grouping, historical chronology and statistical sufficiency. It neither completes ST081/ST126 nor changes schema, provider, UI, production or security authority. No floating monetary conversion, rounding, normalization factor or configurable multiplier is introduced. Existing Money behavior remains intact.

Validation gates: independent arithmetic/contract plan review; root exact mathematical boundaries and meaningful tests; full Money regression and new-helper 100% branch coverage without weaker configuration; lint/typecheck/build; independent frozen-source review; staged secret scan; all actual CI steps before merge.
