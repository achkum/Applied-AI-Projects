# ADR-0007: Deterministic money in integer minor units; LLM never computes

- Status: Accepted (seed ADR, founder may veto per ASSUMPTIONS.md)
- Deciders: architect-platform, Conductor

## Context
This is a financial product. LLM arithmetic is unreliable and unauditable.

## Decision
`packages/money` with bigint minor units, largest-remainder allocation, and greedy netting for settlement (deterministic tie-breaks by member id). LLM output passes the numeric post-check.

## Consequences
+ Correct and testable. − Narratives are constrained to the numbers provided.
