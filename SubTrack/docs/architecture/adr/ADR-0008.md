# ADR-0008: Deploy with Docker Compose + Caddy on a single VPS; HTTPS on bare IP via Let's Encrypt IP certificates

- Status: Accepted (seed ADR, founder may veto per ASSUMPTIONS.md)
- Deciders: architect-platform, Conductor

## Context
There is one RackNerd VPS and no domain yet.

## Decision
Compose stacks for staging and demo. Caddy terminates TLS using an ACME `shortlived` profile certificate for the public IPv4 (~6-day validity, auto-renewed). When a domain is bought, switch the Caddy site address; nothing else changes.

## Consequences
+ Free, simple. − Single point of failure; IP certs are unsuitable for some OAuth redirect allowlists or universal links, which may force buying a domain for Tink redirect / iOS universal links (tracked in RISKS).
